# Contributing to env-clinic

Thanks for considering a contribution.

## Found a Bug?

Please open an issue at https://github.com/ChloeVPin/env-clinic/issues. A small pull request with a focused fix is welcome.

## Have an Idea?

`env-clinic` is designed to stay focused and zero config. Before submitting a major feature, please open an issue so the scope can be discussed first.

## Development Setup

1. Fork the repo and clone your fork:

   ```bash
   git clone https://github.com/ChloeVPin/env-clinic.git
   cd env-clinic
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the tests:

   ```bash
   npm test
   ```

The tests use the native Node.js test runner. Ensure all tests pass before submitting a PR.

## Submitting a Pull Request

1. Create a new branch: `git checkout -b my-feature-branch`
2. Make your changes.
3. Commit your changes: `git commit -am 'Add focused change'`
4. Push to the branch: `git push origin my-feature-branch`
5. Submit a pull request.

## Code of Conduct

Be respectful, constructive, and clear.
